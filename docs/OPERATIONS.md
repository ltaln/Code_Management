# 运行、发布与故障恢复

## 本次可运行内容

仅 `scripts/verify_assets.py` 和 `scripts/wake.py`。依赖 Python 3.10+ 标准库。无环境密钥要求。资产校验不会执行任何预测或采集。

## 发布资产

先校验 Hash、JSON 与本地链接，再检查变更、提交及远端 SHA。冻结内容变更必须保留来源与审阅证据，不能自动刷新锁绕过检测。公开仓库不存私人对话全量、API 密钥或运行日志。

## 后续服务接入

依 Phase 3–5 契约实现持续任务 worker 与接口；在部署环境配置服务地址和凭据；解决 GAPS 后执行 require-ready 和端到端验收。仅把 config 开关改为 true 不代表完成部署。ChatGPT 手机交接连接未建立时，README 命令示例不是已可用的聊天指令。

## 故障处理

资产 Hash 不符：停止加载，保留差异，恢复已知正确版本后复验。模型资料不全：记录 BLOCKED，不生成替代 Prompt。网络失败：有限重试，保留 task_id。采集内容错配：隔离字段、记录来源与原因，按原模型规则处理。提交回执未知：查归档和远端提交后恢复，禁止重复预测。

## 回滚

工程配置回滚到上一验证过的 Git 提交，不改原预测。稳定模型与 Prompt 保持原 Hash；变更发布指针须核验兼容性。空仓库首次发布没有“上一稳定工程版本”，需明确这一点，不创建虚假历史标签。
