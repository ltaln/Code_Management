# Phase 4 · 数据服务器接口

## 输入

任务范围与数据策略。

## 交付

data_engine 的接口与快照合同。

## 退出条件

日期与跨午夜正确；身份错配隔离；来源可追溯；预测只读取本任务最新快照。

## 当前状态

0.3.0 已接入现有自建 Firecrawl HTTPS 服务；持久后台调用原采集代码，保存原始页、identity-v1 逐场包、SHA-256 回执。支持 PARTIAL、取消与中断恢复。

预测任务每次强制重新采集；新预测成功采集后只保留这一次预测目录。独立采集和回测旧数据不被预测读取。

失败处理：保存输入标识、异常、已完成步骤和恢复点；不能把文档生成视为执行验收通过。模型变更仍受冻结规则约束。
