# 第十三重要注意事项：现行规则索引

这是 S01–S04 的适用关系整理，不替代冻结原文或补造 Prompt。

1. 启动前先读取重要注意事项，验证模型版本、Prompt、Upgrade Package 状态和可运行条件。
2. 预测和回测都必须加载完整对应 Prompt；禁止无 Prompt、简化 Prompt 或临时改写。
3. 实时预测重新采集，绑定唯一新数据包；禁止复用旧 Prediction、旧分析、旧 Commit 作为实时预测输入。
4. 回测采用 S04：先检查 Prediction Commit、Prediction Data Package、Prediction Result 与 Execution Log。回测可以读取服务器旧采集数据；读取失败不等于不存在。
5. 不得简化流程、跳过模块或只输出最终比分；记录逐模块输入来源、结果、异常与简要依据。
6. 数据错配字段权重为 0，保留异常证据，其他模块按原规则继续；缺失数据、来源冲突应标记并按原模型降低权重/Confidence，不编造补齐。资产缺失、Prompt 缺失或版本失配是启动失败，与单场字段异常分别处理。
7. 禁止未来信息和赛后信息污染预测；禁止修改历史预测或按赛果调整参数。
8. 新预测必须留存新的 Prediction Commit 和 Execution Log；直接评估既有预测时保留原预测，新增评价记录。
9. 输出顺序：精准比分 → 半全场 → 其他市场（亚洲盘、大小球、胜平负、总进球、其他）。
10. GitHub 保存资产、版本和提交证据；GPT 执行预测。Upgrade Package 1 = PARKED，禁止自动升级。

S01 的数据质量 <70% 降低 Confidence 和 S03 的 DCS 分档同时保留，未假定二者是同一数值。S03 的 100+ 场样本、统计分析、升级提案、人工批准是未来模型调整门槛，不构成本次升级授权。
