# 十一、Prediction Commit 标准


每次预测必须生成：

```
Prediction Commit ID

包含：

- Data Hash
- Model Version
- Timestamp
- Match List
- Prediction Result
- Calibration Result
```

禁止：

覆盖旧 Commit。
