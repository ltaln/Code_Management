# 六、核心分析模块

---

# Module 1
# Water Market Core

核心：

盘口资金模型。


输入：

```
Asian Handicap
European Odds
Movement
Volume
Closing Line
```

分析：

## 1. 初盘

例如：

```
主队 -0.5
```

## 2. 变化

例如：

```
-0.5 → -0.25
```

判断：

市场真实方向。


---

输出：

```
Market Direction Score

0-100
```

例如：

```
Home pressure:
72

Away resistance:
61
```
