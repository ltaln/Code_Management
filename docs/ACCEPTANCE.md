# 验收清单

## 本次资产验收

- 源材料有 turn ID / 附件标识与 Hash；Prompt 与原代码块逐字一致。
- 规划目录均有实际文件；README、记忆、唤醒和六阶段文档可读取。
- 冻结文件缺失、内容变化、新增未锁文件能被检测；JSON 和相对链接通过校验。
- 唤醒脚本先校验再给状态；运行未准备好时 require-ready 返回非零。
- 正向、负向验证证据保存在 VALIDATION.md，不用测试输出冒充预测结果。

## 后续完整系统验收（尚未完成）

- 同一场比赛在确认的原执行环境和接入环境使用相同数据、模型、Prompt，对照模块与输出，说明允许的 GPT 随机性；不以本次测试偷偷改权重。
- 一条命令完成持久任务、采集、全部模块、归档与结果返回；手机关闭后仍可查询完成状态。
- 超时重试、worker 重启、重复事件、取消、部分场次失败均留存恢复证据。
- 身份错配、跨午夜、旧快照、未来数据、缺字段、档案不可访问有明确处理。
- 回测命中旧档案零重预测；历史重建无赛后污染；评价不修改原预测。
