# 冻结执行流程

最终执行顺序来自 S03 的“更新后的完整运行流程”。原始对话中，用户在看到完整增强建议后明确回复“可以。按照你的意见增加这些内容”，随后系统确认这些内容属于 Operational Framework Update，模型核心、权重和参数不变。2026-09-05 已在登录的 ChatGPT 原始对话中重新核验这段上下文。

重要注意事项 → Model Health Check → Prompt Loading → Fresh Data Collection → Data Package ID → Data Hash → Data Consistency Audit → Data Confidence Score → Water Market → Team Analysis → League Analysis → Company/Source Analysis → Correct Score → SoccerSTATS HT/FT → Odds Abnormal Detection → Match Risk Engine → Conflict Detection → Cross Model Interaction → Calibration → Prediction Commit → Execution Log → Final Report。

Prediction Archive First 是 S04 对回测数据策略的后续修订：存在有效档案时直接评价；回测也可以读取服务器旧采集数据。预测不能读取旧采集，每次命令必须重新采集。

S07 的 Firecrawl 门、DNA、八个独立市场、PASS、结果解锁与评分规则作为累积硬规则继续执行；T-30 已按用户 2026-09-06 指令取消。v1.1 是 S07 内部基线标签；HH520-PROMPT-V2.1 是当前外层运行提示词版本。两者职责不同，不再视为互相替代的冲突版本。

核心预测由 GPT 依据资料定性推理。已有 DCS 权重和分档照原文执行；原文没有给出的 Poisson 系数、融合公式、校准幅度不得由程序补造。
